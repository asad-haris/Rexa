# Rexa - AI Resume Screening and Ranking System 🚀

**Rexa** is an intelligent resume screening app built with **Streamlit** and **Python**. It parses resumes, compares them to a job description, and ranks the best matches using **Natural Language Processing (NLP)**.

---

## 🔍 Features

- Upload multiple PDF resumes 📄  
- Upload a job description 📃  
- Extract and process text from resumes  
- Calculate similarity scores using NLP  
- Rank resumes based on relevance  

---

## 📁 Project Structure

```
Rexa/
├── app.py                 ← Main Streamlit app
├── resume_parser.py       ← Resume text extraction logic
├── matcher.py             ← Matching logic using NLP
├── utils.py               ← Helper functions
├── resumes/               ← Folder with uploaded/sample resumes
├── job_description.txt    ← Job description file
├── requirements.txt       ← Python dependencies
└── README.md              ← Project documentation
```
